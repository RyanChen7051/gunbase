# 产品图片目录（images/）

把产品图片放进这个文件夹，即可在网站上显示。

## 命名约定（推荐）
用产品的 **SKU / 货号** 作为文件名，例如：

- `RDS-57.jpg`
- `VISION-650.png`
- `WL-25.webp`

## 如何关联
有两种方式让某件产品显示这张图：

1. **商家后台（admin.html）导入 Excel** 时，在 `image` 列填文件名即可，例如 `RDS-57.jpg`
   （系统会自动解析为 `images/RDS-57.jpg`）。

2. **手动**：直接编辑 `js/products.js`，把对应产品的 `image` 字段改成文件名：
   ```js
   image: "RDS-57.jpg"
   ```

## 解析规则（js/app.js → imgSrc）
- 空字符串 → 显示准星占位图（默认）。
- 以 `http://` / `https://` / `data:` / `/` 开头 → 当作完整 URL 或站点绝对路径，原样使用。
- 含 `/` 的路径 → 原样使用（如 `images/xxx.jpg`、`https://...`）。
- 其它纯文件名（如 `RDS-57.jpg`）→ 自动加 `images/` 前缀。

## 图片建议
- 正方形或 4:3，背景干净，建议 800×800 以上。
- 支持 jpg / png / webp。
- 单张控制在 300KB 以内，保证 PWA 离线包体积与加载速度。
- 若某张图加载失败，会自动回退为准星占位图，不会显示破图。

> 注意：部署到 GitHub Pages 等静态托管时，images/ 文件夹需一起上传；PWA 离线缓存（sw.js）默认只缓存核心文件，图片按需联网加载。
